```python
URLS = [f"https://picsum.photos/seed/{i}/800/600" for i in range(20)]


def timed(label, fn, *args):
    """Запускает fn(*args) и печатает, сколько секунд она работала."""
    start = time.perf_counter()
    fn(*args)
    print(f"{label}: {time.perf_counter() - start:.2f}s")
```

### Задание 0. Разминка-ловушка «Почему не быстрее?»

Ниже готовая функция `slow_main`. Она написана на async, но работает не быстрее обычного цикла с `requests` — в этом и ловушка.

- Замерь её время работы.
- Объясни, почему async здесь не дал ускорения.
- Почини.

```python
async def fetch(client: httpx.AsyncClient, url: str) -> int:
    resp = await client.get(url)
    return resp.status_code


async def slow_main():
    async with httpx.AsyncClient(follow_redirects=True) as client:
        for url in URLS:
            await fetch(client, url)  # <-- разобраться и починить


# Запуск и замер — добавь в конец файла:
timed("slow ", lambda: asyncio.run(slow_main()))

# lambda нужна, чтобы запуск произошёл ВНУТРИ timed: если написать
# timed("slow ", asyncio.run(slow_main())), корутина выполнится ещё
# до начала замера, и timed получит уже готовый результат.
```

Обрати внимание на `follow_redirects=True`: picsum отвечает редиректом 302, и `requests` сам идёт по нему, а `httpx` — нет. Без этого флага асинхронные версии будут «скачивать» короткие 302-е ответы вместо картинок — сравнение с `requests` получится нечестным, а в задании 2 `raise_for_status()` начнёт падать на каждом URL. Флаг нужен во всех `AsyncClient`.

### Задание 3. Вынос CPU-bound-вычислений

После скачивания посчитай что-то тяжёлое по каждому ответу — в скелете это `heavy`: sha256 от искусственно раздутого тела ответа.

Как увидеть, что event loop встал: в скелете есть корутина `ticker`, которая печатает точку каждые 0,1 секунды. Пока точки бегут — loop живой; точки замерли — loop заблокирован.

- Сделай «в лоб» — вызови `heavy` прямо в корутине и заметь, что точки замерли.
- Вынеси вычисления в отдельный процесс (`run_in_executor` + `ProcessPoolExecutor`) и покажи, что точки снова бегут.

```python
import hashlib
from concurrent.futures import ProcessPoolExecutor


def heavy(body: bytes) -> str:
    # body * 1000 раздувает данные, чтобы хеш считался заметно долго
    return hashlib.sha256(body * 1000).hexdigest()


async def ticker():
    # «пульс» event loop: если точки перестали печататься — loop заблокирован
    while True:
        print(".", end="", flush=True)
        await asyncio.sleep(0.1)


async def cpu_main():
    ...  # 1) запусти ticker фоновой задачей: asyncio.create_task(ticker())
         # 2) скачай ответы и посчитай heavy «в лоб» — точки замрут
         # 3) посчитай heavy через loop.run_in_executor + ProcessPoolExecutor —
         #    точки бегут
         # 4) в конце отмени ticker через .cancel()


if __name__ == "__main__":
    # проверка обязательна: без неё ProcessPoolExecutor падает на Windows
    # и macOS — дочерние процессы заново импортируют этот файл
    timed("cpu  ", lambda: asyncio.run(cpu_main()))
```
